# MediTrack Database Project

## Project Overview
MediTrack is a database management project developed using MySQL. It demonstrates how relational databases are created, managed and queried using SQL.

## Database Name
meditrack_db

## Technologies Used
- MySQL
- SQL
- MySQL Workbench / MySQL Command Line Client

## Project Objectives
- Create and manage relational database tables.
- Insert and maintain records.
- Retrieve information using SQL queries.
- Establish relationships using primary and foreign keys.
- Analyze data using joins and aggregate functions.

## Database Operations
- Database Creation
- Table Creation
- Data Insertion
- Data Retrieval
- UPDATE and DELETE
- WHERE and ORDER BY
- GROUP BY and HAVING
- Aggregate Functions
- SQL Joins

## Project Files
- meditrack_database.sql – Database creation, table definitions, sample data and SQL queries.
- screenshots/ – Screenshots of query execution and outputs.

## How to Run
1. Open MySQL Workbench or MySQL Command Line Client.
2. Open meditrack_database.sql.
3. Execute the SQL statements in the correct order.
4. Verify the created tables, inserted records and query results.
